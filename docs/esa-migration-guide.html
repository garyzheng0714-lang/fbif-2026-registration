Step 3

回源协议HTTPS
回源端口443（Caddy 继续处理源站 HTTPS）
源站地址121.40.214.5

ESA 节点会将请求转发到你的 Caddy，Caddy 再转 Nginx 再转 API 容器，现有架构完全不动。

Step 4
申请 SSL 证书

进入 SSL/TLS → 边缘证书，为域名申请免费证书。

证书状态必须变为「已签发」才能继续！HTTPS 握手依赖此证书，未签发时 HTTPS 访问会报错。这是之前测试域名踩过的坑。
Step 5
配置缓存规则
/assets/*缓存 30 天 (immutable)
/api/*不缓存（回源）
/health不缓存（回源）
/不缓存 (no-store)

与现有 Caddy 缓存策略保持一致。

Step 6
配置安全防护
  • WAF — 开启托管规则
  • DDoS — 默认已开启基础防护
  • 速率限制 — 按需配置（现有 API 已有 express-rate-limit）

Step 10（提前 1-2 天）
降低 DNS TTL

去 DNS 服务商，将 fbif2026ticket 记录的 TTL 从默认值（通常 600s）改为 60 秒。

等待旧 TTL 过期后，全网 DNS 缓存刷新，切换时就能在 60 秒内生效。

Step 11

  旧缓存用户 → 直连源站 121.40.214.5 → 正常

1
证书先签好

2

3

Caddy/Nginx/API 容器完全不变，旧路径和新路径都通。
4

DNS TTL 降至 60 秒，切换后最多 1 分钟全网生效。
5
原子操作
只改一条 DNS 记录，出问题改回 A 记录即可秒回滚。
紧急回滚方案
如果切换后发现问题，去 DNS 服务商将 CNAME 记录改回 A 记录：

fbif2026ticket → A → 121.40.214.5

因为 TTL 已设为 60 秒，回滚后 1 分钟内全网恢复直连源站。ESA 侧配置不用删，下次测试好了再切回来。
