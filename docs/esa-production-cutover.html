ESA 正式站切换

fbif2026ticket.foodtalks.cn

阶段一：在 ESA 控制台配置 不影响线上

1. 新增站点

站点管理 → 新增站点 → 输入 fbif2026ticket.foodtalks.cn → 接入方式选 CNAME → 加速区域选 中国内地

2. 验证域名归属权

ESA 会要求你证明这个域名是你的。去你的 DNS 服务商（管理 foodtalks.cn 的地方）加一条记录：

  • 类型：TXT
  • 主机记录：ESA 页面显示的值（类似 _esaauth.fbif2026ticket）
  • 记录值：ESA 页面显示的验证码（点复制按钮）

加完后回 ESA 点「点击验证」，通过后进入下一步。

3. 添加 DNS 记录

DNS → 记录 → 添加记录：

  • 类型：A/AAAA
  • 主机记录：@
  • 记录值：<源站IP>
  • 代理状态：开启

添加后页面会显示一个 CNAME 地址，复制保存。

4. 申请 SSL 证书

SSL/TLS → 边缘证书 → 申请免费证书 → 域名填 fbif2026ticket.foodtalks.cn

ESA 会再让你去 DNS 服务商加一条 CNAME 验证记录（和第 2 步类似，按页面显示的值填）。

等证书状态变为「已签发」再继续，这步最关键。

5. 配置缓存

缓存 → 缓存规则 → 添加：

  • /assets/* → 缓存 30 天
  • 其他（/api/*、/）→ 不缓存

阶段二：本地验证 不影响线上

6. 用 hosts 文件模拟切换
# 查 ESA 节点 IP（CNAME 地址换成第 2 步保存的）
dig <你的CNAME地址> +short

# 改 hosts（IP 换成上面查到的）
sudo vi /etc/hosts
47.x.x.x  fbif2026ticket.foodtalks.cn

# 刷新 DNS
sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder
7. 打开浏览器验证

访问 https://fbif2026ticket.foodtalks.cn，检查：

  • 页面正常、证书有效（有锁）
  • 身份证验证能通过
  • 表单能提交成功

验证完，删掉 hosts 里加的那行，再刷新 DNS 缓存。

阶段三：正式切换 影响线上

8. 提前 1-2 天：降低 DNS TTL

去 DNS 服务商，把 fbif2026ticket 的 TTL 改成 60 秒。

9. 改 DNS 记录（一步完成切换）

把 fbif2026ticket 的记录从：

  • A → <源站IP>

改成：

  • CNAME → 第 2 步保存的 CNAME 地址

改完后最多 60 秒全网生效，期间新旧路径都通，零停机。

10. 验证
curl -sI https://fbif2026ticket.foodtalks.cn | grep Server
# 看到 Server: ESA 就成功了

出问题？回滚

把 DNS 改回 A 记录 → <源站IP>，60 秒恢复。
